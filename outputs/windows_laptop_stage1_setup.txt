1. CHUẨN BỊ LAPTOP WINDOWS
================================================================================

1.1 Cập nhật và tài khoản Windows

[ ] Dùng Windows 10/11 64-bit đã cập nhật ổn định.
[ ] Tạo một tài khoản Windows riêng, ví dụ: TradingDemo. Không dùng tài khoản công việc.

[ ] Đăng nhập Windows bằng tài khoản TradingDemo trước khi cài MT5.
[ ] Không bật auto-login nếu laptop có thể bị người khác truy cập.

1.2 Điện, nhiệt và mạng

[ ] Cắm sạc chính hãng liên tục; dùng ổ cắm chống sét hoặc UPS nếu có.
[ ] Đặt máy nơi thông thoáng, không để trên chăn/đệm, không đóng máy vào túi.
[ ] Ưu tiên Ethernet. Nếu dùng Wi-Fi, cố định gần router và tắt chế độ tiết kiệm điện Wi-Fi.
[ ] Không chạy game, render, batch backtest dài hoặc phần mềm nặng trong thời gian forward.

1.3 Cấu hình nguồn Windows (làm khi đang cắm sạc)

Settings > System > Power & battery > Screen and sleep:
  - Turn off my screen: 5 hoặc 10 phút (được phép).
  - Put my device to sleep: NEVER.

Control Panel > Power Options > Choose what closing the lid does:
  - When I close the lid / Plugged in: Do nothing.
  - Khi cần kiểm tra log, mở máy và dùng bình thường; không tắt nguồn để "đóng" máy.

[ ] Settings > Windows Update: đặt Active hours; không để restart tự động ngoài kiểm soát.
[ ] Device Manager > Network adapters > Properties > Power Management:
    bỏ chọn "Allow the computer to turn off this device to save power" nếu mục này có.

7. TỰ KHỞI ĐỘNG SAU REBOOT / MẤT ĐIỆN
================================================================================

Mục tiêu: MT5 tự mở lại khi người dùng TradingDemo đăng nhập Windows.
Điều này chỉ tự khởi động terminal; sau reboot phải kiểm tra Algo Trading và Journal.

7.1 Task Scheduler

Trong Windows Task Scheduler, tạo HAI task:

  Task 1: MT5-V26-Start
    Trigger: At log on of user TradingDemo
    Action: Start a program
    Program/script: đường dẫn terminal64.exe của C:\Trading\MT5-V26\
    Start in: thư mục C:\Trading\MT5-V26\
    Run only when user is logged on: chọn.
    Run with highest privileges: chọn nếu MT5 được cài theo quyền admin.

  Task 2: MT5-V63-Start
    Làm tương tự, nhưng dùng terminal64.exe của C:\Trading\MT5-V63\.

[ ] Bấm Run từng task để test. Xác nhận mỗi task mở đúng MỘT terminal.
[ ] Không dùng task "Run whether user is logged on or not" cho MT5 GUI.
[ ] Không bật Windows auto-login trừ khi máy đặt tại nơi vật lý an toàn và bạn hiểu
    rằng điều này làm giảm bảo mật.

7.2 Sau mọi reboot/reconnect lớn

[ ] Đăng nhập Windows TradingDemo.
[ ] Kiểm tra cả hai terminal mở đúng account/chart/preset.
[ ] Kiểm tra Algo Trading đang bật.
[ ] Kiểm tra Journal và telemetry có RECONNECT/INIT hợp lý.
[ ] Không đổi preset hay attach lại EA tùy tiện.

8. THEO DÕI HẰNG TUẦN VÀ CỔNG STAGE 1
================================================================================

Mỗi tuần một lần, cho TỪNG account:

1. Account History > chọn Custom Period từ ngày bắt đầu đến hiện tại.
2. Save as Report (HTML).
3. Sao chép vào thư mục tuần riêng:
   - report.html
   - Mentor_RSI_MTF_forward.csv
   - Mentor_RSI_MTF_diag.csv
   - Mentor_RSI_MTF_shadow_signals.csv
   - Experts/Journal log có DIAG_SUMMARY và lỗi EA

Ví dụ thư mục:
  C:\Trading\forward-data\V26\2026-07-31\
  C:\Trading\forward-data\V63\2026-07-31\

4. Chạy trên Command Prompt trong C:\Trading\build-bot\:

  py tools\mt5\report_summary.py --json C:\Trading\forward-data\V26\YYYY-MM-DD\report.html > C:\Trading\forward-data\V26\YYYY-MM-DD\summary.json

  py tools\mt5\forward_gate.py gate --stage stage1 --summary C:\Trading\forward-data\V26\YYYY-MM-DD\summary.json --telemetry C:\Trading\forward-data\V26\YYYY-MM-DD\Mentor_RSI_MTF_forward.csv --journal C:\Trading\forward-data\V26\YYYY-MM-DD\expert-journal.txt --start-date YYYY-MM-DD --end-date YYYY-MM-DD

  Lặp lại cho V63.

Kết quả gate:
  0 = PASS: đạt cổng đang đánh giá.
  2 = WAIT: chưa đủ 90 ngày VÀ 60 closed cycles; tiếp tục nếu không có FAIL.
  3 = FAIL: phải pause và giữ nguyên bằng chứng.

================================================================================
9. PAUSE NGAY - KHÔNG TỰ SỬA THAM SỐ
================================================================================

TẮT Algo Trading của terminal bị ảnh hưởng ngay khi có MỘT trong các điều kiện:

  - Equity DD chạm 8%.
  - Event ACTUAL_RISK_VIOLATION.
  - Event POST_FILL_VIOLATION.
  - Event STOP_MODIFY_FAIL.
  - actual_risk_money vượt desired_risk_money.
  - MISSING_STATE, initialization failure hoặc disconnect chưa reconnect.

Khi pause:
  1. Không xóa CSV/log/report.
  2. Chép toàn bộ evidence vào thư mục dated.
  3. Ghi giờ, account alias và trạng thái position.
  4. Gửi file cho Codex để phân tích. Không tăng risk để "cứu" PF.
